广告与更新上传教程

这个页面只讲两件事：广告传哪里，更新传哪里。你以后照着这份流程改 docs/ 里面的文件就行。

返回网页首页 打开 ads.json 打开 update.json

一、你到底要上传到哪里

这个仓库的网页内容是从 docs/ 目录发布的，所以你只要把内容放到这里：

docs/ ├── ads.json 广告列表，软件读取这个 ├── update.json 更新列表，软件读取这个 ├── ads/ 广告图片放这里 └── download/ 更新安装包放这里
最重要的是：图片和安装包都先放在 docs/ 里，再把对应链接写进 json。软件里填的是 json 地址，不是图片文件地址。

二、广告配置生成器怎么用

这一步就是照着你软件里的窗口来。顺序别乱，先做广告内容，再导出，再上传，最后回到软件里填网址。

1. 打开广告配置生成器 在软件里点“管理广告”，进入这个窗口后，先看左上角的广告列表区。
2. 点击“添加图片广告” 选一张广告图，再填“广告名称”和“点击跳转网址”。广告名称只是方便你自己管理，用户一般看不到。
3. 需要多条广告就重复添加 每一条广告都可以单独启用或删除。你想放几条就加几条，做完一条就继续下一条。
4. 点“导出广告包” 软件会帮你打包生成带签名的 ads.json 和 ads 图片文件夹，后面上传到网页目录里。
5. 把导出的文件传到网页目录 把导出的 ads.json 和 ads 文件夹，上传到 GitHub 仓库的 docs/ 目录里。
6. 回到软件里粘贴网址 把上传后的 ads.json 地址填到“云端 ads.json 地址”里，然后点“测试读取”。
7. 测试成功后保存 看到测试成功，再点保存。这样广告以后就会从网页地址里读取，不用每次重新填。 
{
  "version": 1,
  "updatedAt": "2026-08-22T12:00:00.000Z",
  "ads": [
    {
      "id": "ad-1",
      "title": "示例广告",
      "imagePath": "ads/ad-01.png",
      "url": "https://example.com",
      "enabled": true
    }
  ]
}

如果图片和 ads.json 在同一个网页目录里，imagePath 用相对路径最稳。导出的 ads.json 已经带签名，不要手动改里面的内容，改了签名会失效。

三、更新怎么上传

1. 上传安装包 把新版本安装包放到 docs/download/，例如 AI素材库-v1.0.1.exe。
2. 用管理版导出 update.json 在管理设置里填写版本号、安装包下载链接，选择本地安装包计算校验值，然后导出带签名的 update.json。
3. 软件里粘贴 更新地址填 https://你的用户名.github.io/仓库名/update.json。
4. 发布后等待生效 网页发布通常几分钟内刷新完成，旧版本用户下次检查更新就会看到新版本。 
{
  "version": "1.0.1",
  "title": "发现新版本",
  "notes": ["修复若干问题", "优化启动速度"],
  "installerUrl": "https://你的用户名.github.io/仓库名/download/AI素材库-v1.0.1.exe",
  "fileName": "AI素材库-v1.0.1.exe",
  "sha256": "",
  "force": false
}

新版软件会检查 update.json 的签名。以后请用管理版导出 update.json，不要手动改签名字段。

四、在软件里哪里填

1. 打开软件的设置 点软件里的“AI 设置”，会看到上半部分是 API 设置，下半部分是广告与更新。
2. 上半部分填 API 这里填的是 API 地址、API Key、模型名称。填好后点“保存 API 设置”。
3. 下半部分填更新地址 把 update.json 的网址贴到“update.json 地址”里，然后点“保存广告/更新”。
4. 广告单独管理 点“管理广告”，进去后按前面那一套：添加广告图片、导出广告包、上传到网页、填写网址、测试、保存。
5. 默认收起管理员区 普通用户打开软件时默认看不到广告和更新地址，只有点“展开管理员设置”才会出现。
你以后记住一句话就行：网页里改的是文件，软件里填的是地址。
上面那块是 API，下面那块才是广告和更新，两个保存按钮各管各的。

五、网页版仓库具体怎么点

步骤 1：仓库首页 打开你的仓库，看到文件列表后，右上方通常有“添加文件”相关按钮。
步骤 2：上传文件页 点“上传文件”后，把 ads.json、update.json、图片或安装包拖进去。
步骤 3：提交按钮 页面下方点“提交更改”，提交后网页会重新发布。
你可以按这个顺序操作 打开仓库 -> 上传文件 -> 修改 json -> 提交 -> 等网页刷新 -> 回软件里点“测试广告 / 检查更新”。

六、以后换广告要不要删旧图

不一定要删。只要 ads.json 不再引用旧图，旧图放着也不会影响新广告。等你确认不用了，再清理旧文件也行。

七、以后换更新包要不要删旧包

也不一定。只要 update.json 指向新的安装包，旧 exe 可以先保留，等你想整理仓库再删。

八、软件里填什么

只填两个地址：ads.json 和 update.json。这两个地址保存一次就够了，不用每次改广告都重新填。

九、最常见的 3 个问题

  • 问题： 图片上传了，软件不显示。
    答： 检查图片是不是还写着本地路径，应该写成网页发布后能访问的相对路径或完整网址。
  • 问题： 更新包上传了，软件还是老版本。
    答： 检查 update.json 里的版本号是不是比当前软件版本大。
  • 问题： 每次上传都很麻烦。
    答： 以后只更新 ads.json、update.json 和对应新文件，不需要重建整个仓库。
